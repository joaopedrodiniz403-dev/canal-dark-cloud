# Nuvem Escura — execução

`python agent/produce.py` chama o novo motor documentado no [README principal](../README.md).

Cadastre vídeos em `sources.json`. `authorized_clips.json`, `topics.json`, `config.json` e `score.py` são arquivos legados preservados para auditoria e **não são utilizados**. O sistema não gera slides/eSpeak quando falta mídia autorizada.
